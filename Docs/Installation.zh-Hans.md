# Claude Guard 0.2.5 测试版

面向 Shadowrocket 系统隧道的原生 macOS 整机防护工具。菜单栏小面板显示保护状态、最近观测出口、隧道和上传／下载速率。点「打开 Claude Guard」进入总览、链路防护、监测与报告。主应用和独立恢复工具都支持简体中文、英语，以及跟随系统、浅色、深色三种外观。支持 macOS 13 及更新版本、Apple Silicon 和 Intel。

## 安装与本机验收

1. 在 Mac mini 双击 DMG，把 **Claude Guard** 和 **Claude Guard Recovery（网络恢复）** 拖进「应用程序」。联网时先打开两个应用，确认本机都能启动。此版本使用临时签名，未经 Apple 公证。如果 macOS 拦截启动，先核对来源，再按系统提示查看「隐私与安全性」。两个应用均无需 Node 或终端。[Apple 说明](https://support.apple.com/zh-cn/102445)
2. 在 Shadowrocket 连上要使用的固定节点，再到 Guard 点「重新检测」。填写 VPS IPv4，访问一个普通网页产生流量，再点「按 IP 识别端口和协议」。也可在 3x-ui 复制支持的单节点链接，点「从剪贴板读单节点」。批准出口默认同节点地址，实际不同则单独填写。节点须能凭固定 IPv4 和端口重连，额外依赖 DNS、登录或订阅刷新可能导致恢复失败。
3. 在 Mac mini 本机关闭 Claude，结束正在运行的任务，再点「60 秒试运行」并授权。启用会重置已有 PF 连接状态。等界面显示「整机保护中」，用普通网页验证能加载新内容。断开 Shadowrocket，确认网页无法再请求新内容。再重连，确认稳定性验证期间网页仍无法联网。试运行到期保持拦截。
4. 验证通过后点「持续保护」。在现场可以接触键鼠时，测试 Wi-Fi 关闭、切网与睡眠唤醒。批准线路会保存在本机。关闭窗口不影响后台守护。Mac 重启会清除会话规则，打开 Guard 点「启用上次线路」重新授权。切换节点或重建 VPN 服务后，需要重新试运行。
5. 要主动解除拦截，先关闭 Claude，再点「恢复网络」。主应用无法打开时，在「应用程序」双击独立的 **Claude Guard Recovery** 并在本机授权。恢复工具可以离线启动。VPN 仍断开时，撤销规则可能恢复直连。「监测与报告」支持导出本机事件，分享前可给公网 IP 打码。

如果 0.2.4 或更早的版本仍在保护，先关闭 Claude，在目标机本地恢复网络，再替换两个应用并重新启用。

## 每一层如何保护

- **本地接入**。Mac 的 Wi-Fi 或网线仍经本地运营商。规则保留本机回环、基础 IPv4 DHCP 和一条指定 VPS 的公网连接，回包只匹配同一接口上本机发起的连接。ARP 和 Wi-Fi 管理帧属于 IP 过滤范围之外。VPS 例外按 IP、端口和协议匹配。
- **传输安全**。单节点链接在本机解析，仅保留端点与传输类型，链接原文和凭据不会保存。若链接明示无加密或跳过证书验证，该端点在复核正确配置前不能启用。链接可声明 TLS、REALITY 或 QUIC/TLS。未提供或无法识别时标记「尚未核对」。Shadowrocket 与 VPS 负责实际握手，Guard 无法验证握手，也无法发现同一服务内手动替换节点配置。[Xray 传输文档](https://xtls.github.io/en/config/transport.html)
- **隧道过滤**。批准的 Shadowrocket 隧道通过出口复验后，仅放行其 IPv4。非回环 IPv6 持续拦截，包括隧道内 IPv6。物理网卡上的直连 DNS 和普通应用流量走默认阻断规则。独立的 Tailscale 接口没有例外，访问 Linux 的实际行为要在严格模式下实测。
- **故障恢复**。Wi-Fi 断开且没有可用的 IPv4 接入时，界面显示「本地网络不可用」，应用保持拦截，暂停出口探测和 VPN 重试。macOS 恢复 Wi-Fi 或切到网线后，守护才继续处理。若原 VPN 仍显示连接、主备探测连续两轮都失败，守护会尝试重启这一个 VPN 服务一次。VPN 断开后，守护保留固定节点连接，并请求 macOS 重连原服务，失败会延长重试间隔。候选隧道先只放行 IPv4 HTTPS 出口探测。在同一隧道、同一可见 IPv4 路由上，连续至少六次通过、覆盖至少十五秒，才恢复普通应用。恢复过程中失败或换路由会重新计数。运行中单次无结果可在原隧道上快速复查，物理网卡直连规则一直有效。确认出口错误或持续探测失败会拦截普通应用。
- **监测与报告**。实时速率读取系统接口字节计数器。事件存在本机。探测经指定隧道访问同一服务商的两个 HTTPS 地址，只采样出口，不采集应用报文内容。

## 这版的验收范围

构建已校验 PF 规则语法和模拟守护状态机。IPv4、IPv6、DNS、断线与恢复仍需在你的 Mac mini 上验收，要确认是否有意外流量，需另外观察物理网卡。重启、强制结束守护或第三方改动 PF 会影响保障范围。守护收到退出信号时会尝试维持拦截，界面会提示失联或规则被改动。测试请保留本地访问，整机拦截也可能切断远程恢复。Apple 将 PF 作为系统管理功能。[Apple TN3165](https://developer.apple.com/documentation/technotes/tn3165-packet-filter-is-not-api)
