Claude Guard

This private installer adds the application, a background guardian and an independent recovery helper. macOS requests administrator authorization.

Close protected applications before installing or upgrading. An upgrade pauses release and preserves restrictive rules during replacement.

The private build uses local code-integrity checks and requires no paid developer certificate. Open only an installer you trust, and verify its supplied checksum.

The application starts automatic checks after installation. These checks may block ordinary traffic until a qualifying VPN path is available. Keep the supplied offline recovery package locally.
