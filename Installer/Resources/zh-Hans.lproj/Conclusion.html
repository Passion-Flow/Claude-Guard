安装完成

Claude Guard 会在登录会话中自动启动。连接 Shadowrocket 后，应用会自动检查支持的配置、节点、出口、稳定性及住宅线路风险。无需填写节点参数或个人 API 密钥。

试运行通过后选择「持续保护」，以后会在开机时恢复保护。升级后请选择「恢复保护」。

Claude Guard Recovery 可在本机离线使用。如果后台服务不可用，其恢复安装包会请求管理员授权，无需互联网即可恢复网络。

卸载时，请先从应用菜单选择“Claude Guard → 卸载 Claude Guard…”。不要先使用清理工具或把应用移入废纸篓；只删除应用不会解除系统防护。

独立离线卸载包保存在 /Users/Shared/Claude Guard Recovery/Uninstall.pkg。即使应用或后台组件已经被删除，它仍可运行。请保留安装镜像作为另一份恢复副本。
