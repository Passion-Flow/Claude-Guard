# Security Policy

Report suspected vulnerabilities privately through GitHub Security Advisories on this repository. Do not open a public issue.

Include the affected version, macOS version, reproduction steps, and whether the report concerns rule enforcement, privilege handling, or the build.

The private edition's current installation, trust model and enforcement limits
are described in [Installation](Docs/Installation.md). Its required physical
verification is recorded in [Target acceptance](Docs/Acceptance.md). Do not
include credentials, node addresses, account identifiers or packet payloads in
a shared report. Keep reproducible source and the exact installer checksum.
